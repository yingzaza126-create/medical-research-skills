# medical-research-skills
AI Skills, prompts, and research tools for medical and public health research.

## Skills

- **[`endnote-to-meta-analysis`](.claude/skills/endnote-to-meta-analysis/)** —
  Read an EndNote library / citation export (EndNote XML, RIS, .nbib, .enw) and
  fill three systematic-review deliverables without breaking their structure:
  the meta-analysis extraction sheet, the JBI critical-appraisal table, and the
  PRISMA 2020 flow diagram. Enforces evidence-first extraction (never invents
  effect sizes, counts, or PRISMA numbers) and ships tested helper scripts for
  reference deduplication and template filling.
